# 四条路

DuaerAiDesk 用一张 Duaer 台面接一次项目改动。创建时的背景就是工作。Duaer 只选一次路。

缺陷记下故障、应得的结果和再做一次的方法。后面的任务只修。

新行为记下目标、一条会失败的核对和基线，然后锁定一张图，把风格和布局放上全局卡。设计师不改目录。可以拆任务，也可以把样子退回。

两样都有时，故障先入卡。修复编号挡住新任务。问过一句仍没有答案，或判断没有回来，就走新行为，项目仍然能建。

范围和验收签过字，数字员工才改目录。开始执行会锁住，开变更才清掉。
